# Contributing to ACS

Thank you for your interest in contributing to Air Cargo Simulator (ACS)!

Contributions, bug reports, suggestions, and improvements are always welcome.

## Reporting Bugs

If you encounter a bug, please open an issue using the Bug Report template.

Include as much relevant information as possible, such as:
- Operating System
- ACS Version
- FlightGear Version
- Aircraft Type
- Steps to reproduce the issue

## Suggesting Features

Feature requests and suggestions are welcome. Please open an issue using the Feature Request template to describe your idea.

## Pull Requests

If you would like to contribute code:

1. Fork the repository.
2. Create a branch for your changes.
3. Make your changes.
4. Test them in FlightGear.
5. Submit a Pull Request using the Pull Request template and include a clear description of your changes.

Please keep contributions focused and consistent with the existing code and project structure.

## Development

ACS is written in Nasal and uses the FlightGear Property Tree.

Contributions should remain compatible with the supported FlightGear environment.

## Questions

If you have questions about ACS or contributing, feel free to open an issue.

Thank you for helping improve ACS!
